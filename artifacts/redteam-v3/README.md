## 3. 数据范围以外的真实风险

两路均构造了当前生成器无法产生的超大整数数据：SQLite 乘法转浮点或 SUM 溢出会造成真值计算错误。其中一例正确量为100，SQL算出96，导致错误96得满分、正确100被扣分。该反例保留在原报告中。

本次任务只接收内置快照，不支持外部数据导入，公开 seed 的请求量远低于此范围。本轮不扩展成通用大整数分析引擎；未来若更换数据范围，须先修改数值计算并加入对应测试，不能沿用本轮覆盖结论。

## 4. 评测层的精度边界

验证器可以精确解析最终 JSON 原文；若调用方先用二进制浮点解析，原文中的极小小数可能已丢失。评测脚本须将最终答案原始 JSON 交给验证器，不应在评分前改写数值。该项作为实验 Harness 的配套修正，不改变业务任务和奖励公式。

该链路已修复：评测脚本保留 answer 原始 JSON，用原文评分与落盘；离线分析以 Decimal 比较、字符串展示十进制值。另有[8项原文传递检查](harness-post-fix/check.py)实际通过，覆盖 fenced/plain envelope、三种等价整数表示和极小非零小数。
