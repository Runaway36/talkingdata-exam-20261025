# 冻结题目后的最终模型评测

日期：2026-10-25。题面、业务数据生成、API 与评分器在本轮前冻结，源码指纹见 [frozen-task.json](frozen-task.json)。本轮只增加运行记录、独立作答和核查材料，不因模型结果修改题目或得分规则。

**结论：原定 24 次运行全部执行结束，无基础设施异常；两个新上下文 GPT/Codex sub-agent 均解对 seed17。补充 DeepSeek 思考模式四次中有一次解对。全部真实结果没有非零、非满分答案，因此主要评测采用严格 0/1 成功判据，不声称已经验证连续分数能良好排序 Agent 能力。**

前三行各自的 pass@4 是每个实例四次中至少一次成功的指示值，再对该条件内实例平均。只含三个固定结构实例或一个实例，不是总体成功概率。补充诊断不并入原定批次；GPT 的 Harness、推理与 token 预算未与 API/本地模型对齐，精确部署标识也不可得，不能据此制作公平的模型能力排行榜。

原定两模型均最多12轮，temperature=0.7、top_p=1；Qwen top_k=0，记录互不重叠的本地采样 seed。DeepSeek 服务端采样 seed 不可控。模型只获得题面和业务 API，不提供代码执行、计算器、参考答案、评分反馈或其他尝试的历史。

补充诊断固定四次，不因结果继续扩样本。思考模式下 temperature 被服务端忽略，4096 token 上限与原批不同，详见 [预先记录的诊断条件](score-order-diagnostic-run01/plan.json) 和 [官方参数说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 运行是否正常，失败发生在哪里

- **DeepSeek 原批：**12次都有合法最终 JSON，均为业务错答；65次工具调用全部成功，0次协议错误、0次输出截断。36个期望事件中，等级正确29项、服务集合正确19项、异常量正确0项；漏报7个期望事件、多报13个事件，完整正确事件为0。说明部分信息提取已成功，关键数量仍未算对，不能把0分解释成接口不可用。
- **Qwen 原批：**12次运行结束，11次提交最终答案，其中5次合法但错、6次格式违规；另1次耗尽12轮仍没有最终答案。15次工具调用中1次选择未知工具，另有13次文本协议错误，0次输出截断。负数计数、把host ID当service ID、虚构事件和错误快照均有原始记录。预算耗尽那次保留 `reward=null`；仅在每次尝试的总体均分中按0处理，不冒充验证器曾评分。
- **DeepSeek 补充诊断：**四次实际 reward 为 `0, 1, 0, 0`。满分答案独立取得五类业务数据后给出正确结果。三条未通过轨迹分别出现1、2、3次输出截断；这是该预算下的表现，不能直接归因于业务推理能力不足。
- **GPT 两次：**各调用5次业务 API，分别独立得出 AUTH=48、DB=174、PAY=120，服务集合及 priority 均正确。逐桶推导可复核，并非只依赖评分器返回1。独立上下文和输入限制属于实验协议，不宣称文件系统安全隔离。

此前的 DeepSeek 网络异常、本地 Qwen RuntimeError 没有在本轮复现。Qwen 原报错缺少完整底层诊断，因此根因仍未确认；本轮证明运行路径恢复并完成批次，没有据此宣称已定位硬件或模型问题。

## 分数能否代表表现排序

本批没有自然产生的中间分，不能检验“0 < 分数 < 1 时，高分通常意味着更好的任务表现”。同为0分的答案也有差异：DeepSeek 已查询相关数据、部分服务信息正确；部分 Qwen 答案未查询便编造数据。冻结奖励按完整事件计分，不为单字段局部改善单独给分，无法把这些差异都排序出来。

按用户确认，本轮采用0/1成功判据报告通过情况。现有 `compute_reward` 仍保留题面公布的0～1公式，演示样例仍可产生部分分；**主要评测指标二值化，不等于更改已冻结的评分函数。** 作者构造的0.8/0.4样例只解释公式，明确排除在模型统计之外，不充当实证效度证据。

## 对任务本身的判断

1. **构念与能力范围：**目标明确为给定业务规则下的工具选择、多源关联、时间和维护例外处理、精确聚合与排序。这些是执行业务分析的 Agent 所需能力之一；本题的事件归属已由输入给定，不测发现真实故障根因，也不覆盖所有 agentic 能力。当前仅使用业务工具的模型条件，不代表使用代码计算工具后的能力上限。
2. **可运行与真值：**冻结前完成51项测试、Docker默认运行与目录挂载检查；参考解使用API和Python计算，验证器使用独立SQL，另有独立逐桶复算及本轮真实Agent正确答案。证据见 [执行检查](../../docs/VALIDATION.md) 与 [最终独立核查](independent-audit-final.md)。程序性测试、真实模型评测和独立核查分别报告。
3. **要求、评分对齐与鲁棒性：**已检查正确解被误扣、错误解得满分两类反例；公开输入大小限制、接受等价整数表示并保留精确JSON数值。已有全10,000个内置seed独立核算、2,535个答案变异及协议检查；结果限于当前生成器和已测范围，不能称为穷尽证明。超出生成器范围的SQLite大整数风险和固定结构记忆捷径仍明确保留，详见 [红队处理记录](../redteam-v3/README.md)。

可据此进入考试要求对照与README整理；尚未验证连续奖励的能力排序、跨结构泛化或真实RL训练收益。
