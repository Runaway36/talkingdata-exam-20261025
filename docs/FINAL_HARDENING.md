# 最终交付加固与历史评测兼容性

2026-10-25，模型评测完成后，按审阅意见进行两项局部修复，未修改默认自然语言题面、业务答案或奖励公式。历史模型运行与原始证据保留，没有冒充新源码下重新跑过模型。

1. **桶长配置联动已修复。** `data.py` 从窗口长度和 `BUCKET_MINUTES` 计算桶数、桶起止时间，日期从 `WINDOW_START` 偏移；10分钟配置实际得到每服务3个10分钟桶，API参考解与SQL真值一致。非法桶长、时间格式、非正或超过24小时的窗口、非整桶窗口明确报错。事件的业务相对时间和关系仍是本场景定义，不是任意场景自动生成器。
2. **评分故障与答错已区分。** `evaluate` 在可信快照计算失败时返回专用 `error_code=TRUSTED_SNAPSHOT_UNAVAILABLE`；`compute_reward` 抛出 `VerifierInfrastructureError`，训练方应记录并排除此运行。错误答案和非法任务仍返回0；正常评分报告不增加字段。示例接入与可选模型Runner都检查该故障，不将其误记为Agent业务错答。
3. **固定结构训练捷径尚未解决。** 服务关系、基线和维护结构仍固定，重复训练可记忆这些信息。临近提交没有仓促改动数据分布或重新宣称难度已标定；该边界在README和任务契约中保留。对默认单场景首次独立作答的必要数据依赖，不外推为重复训练后每次都必须查询全部来源。
